# 行動ログ入力システム

スマホでも扱いやすい、GitHub Pages公開用の行動ログ入力Webアプリです。

## 特徴

- ID: 8文字以上の英数字
- パスワード: 12文字以上
- 初回ログイン時に端末へ登録
- ログはパスワード由来の鍵でAES-GCM暗号化してブラウザに保存
- 10秒で入力できる行動ログ
- つまずき要因、気分、実行度、次の最小行動を記録
- JSON/CSVエクスポート対応
- PWA対応。スマホのホーム画面に追加可能

## 重要な安全上の注意

このアプリはGitHub Pagesだけで動く「静的サイト」です。
そのため、サーバー側のログイン認証、全世界でのID一意性確認、複数端末同期はできません。
ログは各端末のブラウザ内に暗号化保存されます。

より高い安全性や複数端末同期が必要な場合は、Firebase Authentication、Supabase Authなどのバックエンドを追加してください。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成する
2. このフォルダ内のファイルをすべてアップロードする
3. リポジトリの Settings → Pages を開く
4. Build and deployment の Source を `Deploy from a branch` にする
5. Branch を `main`、folder を `/root` にして Save
6. 数十秒〜数分後、表示されたURLにアクセスする

## 使い方

1. 初回アクセス時にIDとパスワードを入力
2. 「ログイン / 初回登録」を押す
3. 10秒ログを入力
4. 定期的にJSONまたはCSVでエクスポートする

## ファイル構成

- `index.html`: 画面本体
- `styles.css`: スマホ対応デザイン
- `app.js`: ログイン、暗号化、記録、エクスポート処理
- `manifest.webmanifest`: PWA設定
- `sw.js`: オフライン対応
- `icon.svg`: アイコン
